I created this page to save my time while communicating with recruiters about a job opportunity.

As of time of writing (fall, 2017) among popular pre-screening questions was this particular one &#8212;
  
&#171;React vs Angular?&#187;

Here is my answer:
  
Angular (I suppose next-generation 2+? 🙂 is a perfect fit for Enterprise level complexity of applications, with all the strictness needed there. It also gives opportunity to developers who come from statically typed languages (C#, Java) jump quickly into developing front end parts. Thanks to the TypeScript and the way how Angular framework organized internally. As downsides &#8212; the documentation is overwhelming and should be reorganised/restructured in a better way.

React is what I would use for a new project, especially if it is a POC. You don&#8217;t have to deal with strictness and extra complexity of enterprise-level Angular framework, but rather jump quickly into hacking and creating useful web components. React has very good documentation, which allows anyone quickly find answers to the raising questions.
  
Writing an application with React is very easy, you can choose lightweight pure functional components over the advanced full-featured component.
  
react-create-app made it super easy to start your new project quickly, instead of spending a lot of time which bootstrapping and bringing all parts together.
  
While being small to grasp, React still allows to create an enterprise-level applications, and it also supports Typescript for the lovers.

Visiting meetups, conferences, hackages, reading medium/hackernoon and other topic blogs and publications. Subscribed to Twitter for JSDaily, CSS-Tricks, frontend in general and Framework specific channels. Has an email subscription with a weekly update about things going around.
  
Visiting github trends to see what is ther.
  
I also like looking into source code of different frameworks and libraries, e.g. &#8212; how did Preact do almost all the job which React does, but in such a small size 🙂
