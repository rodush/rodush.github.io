Install libexpat1-dev via apt-get.
  
Then install libcurl4-openssl-dev package with its dependencies:

> The following NEW packages will be installed:
    
> comerr-dev krb5-multidev libcurl4-openssl-dev libidn11-dev libkrb5-dev libldap2-dev libssh2-1-dev libssl-dev zlib1g-dev

После этого можно успешно выполнять команды
  
make clean
  
make
  
make install
